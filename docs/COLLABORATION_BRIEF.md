# Gameplay Evidence Lab: bounded collaboration demonstration

Independent prototype supporting a proposed PhD in **Multimodal Learning of RPG System Interactions for Evidence-Based Game Design**. No institution or industry partner has approved, sponsored or participated in this project merely by being a possible audience.

## Demonstration

Show a fictional session in the synthetic workspace. Open the configuration and a timestamped event, add an explicit review correction, inspect missingness, and export the schema-linked dataset. Then demonstrate local video annotation using an authorised disposable recording. Original reports remain distinct from corrected labels and machine suggestions.

## Engineering evidence

- Strict record and relationship validation shared with the server gate.
- Versioned study/information metadata, explicit unknowns and units.
- Separate synthetic, local and centrally submitted origins.
- JSON integrity manifest, related CSVs, dictionary and grouping aids.
- Database policies for owner isolation and researcher roles, with isolated executable tests.
- Responsive workflow and accessibility checks; live-hosted backend tests require setup.

## Possible bounded request

Request technical feedback on one narrowly defined equipment–action–encounter question, annotation schema or evaluation protocol. If appropriate, discuss a small authorised pilot with agreed data fields, access controls, baseline, permitted processing, retention and publication scope. An anonymised or synthetic representative sample may be sufficient for early discussion.

Do not request unrestricted engine/source access. Do not assume community data confer publisher permission. A partnership would require separate agreement. The instrument can operate independently for personal pilots and suitable editable research environments.

## Current scientific boundary

The prototype prepares evidence. Predictive accuracy, the proposed shared-component model, generalisation, novelty and design benefits remain hypotheses to investigate. A convincing next result would be a transparent personal pilot documenting annotation effort, missingness and reviewer corrections, followed by an appropriately designed extraction benchmark.
