# Visual asset provenance

`src/assets/field-expedition.webp` is an original AI-generated fictional expedition landscape created for this project on 22 October 2026 using the built-in image-generation tool. The brief requested antique naturalist/cartographic illustration, sandstone terrain, a small original research camp and a distant generic winged-reptile silhouette; no franchise monsters, people, logos, text or copied game UI. It is decorative fiction, not an actual Wilds map, gameplay capture or research evidence.

The generated PNG is retained outside the repository. The published asset was resized to 1600 pixels wide and encoded as WebP, quality 82, using Sharp (205,590 bytes versus the 3,414,190-byte generated PNG). Vite bundles it locally with a content hash. No remote image/font service is contacted by the app. “Monster Hunter” describes the independent project's inspiration and intended pilot context; it does not imply Capcom participation or official status.

The journal monogram is typographic “HF”; no publisher mark is used. Display type uses the user's local Georgia/Times serif fonts, body controls use system UI fonts, and the existing Primer CSS package remains the form/button foundation.
